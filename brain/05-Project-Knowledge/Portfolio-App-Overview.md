# Portfolio Web Application Overview

## Summary
This workspace contains a portfolio web application built with React 19, TypeScript, Tailwind CSS v4, and Vite. It showcases development work, project case studies, skill proficiencies, and contact interfaces.

## Technology Stack Specifications

Component | Technology / Library | Version / Purpose
:--- | :--- | :---
Framework | React | 19.1.1
Bundler | Vite | 7.1.7
Language | TypeScript | 5.8.3
Styling | Tailwind CSS | 4.1.13 via `@tailwindcss/vite`
Animation | Framer Motion | 12.27.5
Smooth Scroll | Lenis | 1.3.26
Primitives | Radix UI | Popover, Slot
Icons | Lucide React / Feather Icons | 1.17.0 / 4.29.2
Data Visualization | Recharts | 3.8.1
Insights | Vercel Speed Insights | 2.0.0

## Key Workspace Paths
- `src/App.tsx`: Central component orchestrating page sections, routing, and layout.
- `src/dataset.ts`: Structured datasets defining portfolio items, tech stacks, and career timeline.
- `src/index.css`: Global design tokens, font family imports, and styling base.
- `src/components/`: Modular presentation components.
- `src/lib/`: Shared utilities and class name merger helpers.
- `src/types/`: Type definitions and interface contracts.
